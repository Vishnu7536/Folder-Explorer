# Folder Explorer

## Project Description

Folder Explorer is a simple file browsing application developed using C# and Windows Forms (.NET). It allows users to explore computer drives, navigate through folders, and view files inside selected directories.

The application uses a TreeView control on the left side to display available drives and folders. When a user selects a folder, the ListView on the right side displays the files in Details view, including their names, sizes, and last modified dates.

## Features

- Display available computer drives.
- Browse folders using TreeView.
- Expand folders to view their subfolders.
- Select a folder to display its contents.
- Display files in ListView Details view.
- Show file names.
- Display file sizes.
- Show last modified dates.
- Navigate through different folders.

## Technologies Used

- C#
- .NET
- Windows Forms (WinForms)
- Visual Studio
- System.IO Namespace

## Windows Forms Controls Used

| Control | Purpose |
|---|---|
| TreeView | Display drives and folder structure |
| TreeNode | Represent individual drives and folders |
| ListView | Display files in the selected folder |
| ColumnHeader | Display Name, Size, and Date Modified |
| SplitContainer | Separate the folder tree and file list |

## Main Functionalities

### 1. Drive and Folder Navigation
- Detect available drives on the computer.
- Display drives and folders in TreeView.
- Expand folders when clicked.
- Navigate through the folder structure.

### 2. File Listing
- Display files from the selected folder.
- Show file names.
- Display file sizes.
- Show the last modified date of each file.
